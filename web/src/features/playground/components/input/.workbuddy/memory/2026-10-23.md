
## PlaygroundInputImages 首尾帧模式 (2026-10-23)
- config.createVideoMode === 2 时进入首尾帧模式:两个固定槽位(首帧/尾帧)+ 中间 ⇌ 交换按钮,复用 ImageCard(新增 plain prop:不倾斜、删除角标用 group-hover 控制指针事件)和 uploadSingle 上传逻辑
- 列表类型改为 Slot[] (ImageItem | null),首尾帧模式删除/上传失败只清空槽位不挪位;堆叠模式行为不变
- 对外同步统一走 emitChange:首尾帧模式按槽位打标记(0号槽 isFirstIem:true,1号槽 isSeconfIem:true),堆叠模式不带标记
- 字段名 isFirstIem/isSeconfIem 是用户指定的后端契约拼写(非 typo),不要"修正"
- 清空时机:activeTab 或 isFrameMode 变化时清空
- 已修 bug:首尾帧上传后不回显 —— 列表初始为 [],`prev.map` 在空数组上写入槽位什么都没发生,
  改为 writeSlot(prev, index, value) 先补 null 槽位再写。教训:固定槽位结构不能用 map 赋值
